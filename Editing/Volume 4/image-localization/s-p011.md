### The name across the gutter — and what it means for `s-p010`

`s-p010` prints the furigana `きわだ　ようこ` at its top left and no name kanji. That page's spec
recorded the absence as a probable printing defect. **It is not.** The name kanji is here, set across
the top of this page in display type, and in the original right-to-left binding this page falls to
the *left* of `s-p010`, which puts the furigana on `s-p010` immediately across the gutter from the
kanji it annotates. The two are one typographic unit split by the fold.

That resolves the anomaly but leaves a decision. English has no furigana, so the reading gloss has no
counterpart, and the shipped `s-p010` sets `KIWADA YOKO` in that position. This page sets it too,
because the name is this page's only display element and removing it would leave a bare illustration
under an empty band. The English spread therefore carries the name twice.

That is accepted rather than corrected, for two reasons. The volume ships as an EPUB, where these are
two separate scrolled pages and not a viewed-together spread, so each page needs to stand on its own —
a nameless profile page would be the worse artefact. And every other profile page in this booklet
(`s-p004`, `s-p005`, `s-p006`, `s-p008`, `s-p009`) carries its subject's name on the profile page
itself; dropping it from `s-p010` alone would break that pattern. The note in `s-p010.md` has been
amended so the record is not left claiming a defect that does not exist.
