# Shared Image-Localization Typesetting — Volumes 2–4

This is the reusable typesetting source of truth for localized illustrations in
Volumes 2–4 of *Wand Maker of the Ruined World*. It follows the visual precedent
set by the completed Volume 1 localized assets while making the choices exact
and repeatable. Volume-specific specs may adapt placement to the source artwork,
but must not introduce a different typographic system.

## Font families

- Display titles, character names, section heads, labels, statistics, captions,
  contents entries, and page furniture: **Noto Sans**, with **Noto Sans Bold**
  for the primary hierarchy and **Noto Sans Medium/Semibold** for secondary
  hierarchy.
- Paragraph prose, biographies, commentary, notes, and other long-form copy:
  **Noto Serif Regular**. Use **Noto Serif Italic** only where the source
  explicitly uses an italic or equivalent emphasis.
- Decorative cover/title lettering that is already English is retained rather
  than recreated. When Japanese display lettering must be replaced, use Noto
  Serif Bold or Noto Sans Bold according to the source's serif/sans character,
  preserving the source scale, colour, and orientation intent.
- All English is upright, horizontal, and left-to-right. Never stack one letter
  per line or rotate ordinary English prose to imitate Japanese vertical text.

## Hierarchy and sizing

Sizes are proportional to the image's shorter canvas dimension so the same
logic works across portrait and landscape assets:

- Cover or major display title: 7–12% of the short edge, fitted to the original
  title region.
- Full-page title / character name: 4.5–7%.
- Page or section heading: 2.7–3.5%.
- Subheading, stat name, or strong label: 2.0–2.6%.
- Body prose: 1.55–2.05%, never below the smallest size that remains legible at
  the source image's native dimensions.
- Caption, credit, folio, or minor label: 1.15–1.55%.

Prefer reflowing text and using available negative space over reducing body
copy below the legibility floor. Preserve the source hierarchy even when the
English copy occupies a different number of lines.

## Weight, colour, outline, and shadow

- On white or pale booklet pages: headings and labels use the source navy/dark
  blue (sampled from the page); body copy uses near-black. No outline or shadow.
- On coloured artwork: use the source text colour. Add a contrast treatment
  only when the source uses one or when required for legibility:
  - light text: dark outline 0.10–0.16% of the short edge;
  - dark text: light outline at the same scale;
  - optional soft shadow: offset 0.10% of the short edge with blur 0.18–0.24%.
- Preserve source emphasis: bold remains bold, coloured keywords retain their
  colour role, and display text keeps the source's visual prominence.
- Do not add boxes, banners, gradients, or effects that are absent from the
  source.

## Alignment and spacing

- Match the source text region's alignment: left-aligned prose remains
  left-aligned; centered display text remains centered; right alignment is used
  only when the source composition requires it.
- Body leading: **1.28 em**.
- Compact labels or contents entries: **1.16 em**.
- Display titles: **1.02–1.10 em**, depending on capitalization and line count.
- Preserve every source paragraph break. Within a paragraph, use the applicable
  leading above; between paragraphs, add **0.68 em** after the preceding
  paragraph. Do not represent paragraph separation merely with a normal line
  break.
- Heading-to-body gap: **0.55 em**. Section-to-section gap: **0.90 em** unless
  an existing rule or panel boundary already provides the separation.
- Keep at least 2.5% of the short edge between text and important artwork,
  borders, rules, or trim-sensitive edges.

## Source preservation and verification

- Replace only the transcribed source-language text. Preserve artwork,
  texture, borders, rules, panel geometry, page numbers, existing English
  branding, and all unlisted elements.
- The cover must show **Wand Maker of the Ruined World** only once. Retain the
  existing English title treatment and remove the Japanese title without adding
  a duplicate English title.
- For pre-Chapter-1 colour illustrations, use the corresponding established
  filed English chapter wording verbatim.
- Verify each localized image at native dimensions for exact wording,
  canonical names/terms, placement, hierarchy, line leading, paragraph spacing,
  contrast, and unchanged artwork.
