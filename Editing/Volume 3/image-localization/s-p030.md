## Exact English by region

### P1 — header
```
For Dragons
```

### P1 — body
```
Dragon blood does not boil. Self-blood tanning requires living blood, or blood no more than thirty minutes past death. The fresher, the better. Apart from using that fresh blood unheated, the procedure follows ordinary self-blood tanning.
Blood from a dragon in a self-enhanced state from eating Gremlins cannot be used for self-blood tanning.
```

### P2 — header (two lines)
```
For Using Blood, Sap
and the Like as Material
```

### P2 — body
```
Self-blood tanning cannot be used.
As a simple measure, cold storage will slow deterioration by roughly 5-10%.
Deterioration can also be slowed by replenishing the blood with magic power passed through a Gremlin harvested from the monster the material came from. At present this is possible only when a Transcendent performs the magic-power control, and combined with cold storage it will slow deterioration by roughly 20%.
```

### P3 — header (two lines)
```
For Materials So Oily
They Repel Self-Blood
```

### P3 — body
```
Monsters such as the "oil-licker" and the "oil bee" carry heavy oil in nearly all of their materials, and it repels self-blood as they are, so self-blood tanning needs an added step.
Raise the Gremlin ratio of the self-blood and Gremlin solution sharply, skip dilution entirely, and boil for longer. Reduce the solution until it has evaporated down to solids alone; once the material is covered in those solids with no gaps left, simply carry out the usual natural cooling and washing.
```

### P4 — header (two lines)
```
For Monsters Carrying
Multiple Gremlins
```

### P4 — body
```
Of all the Gremlins that monster carries, powder only the single heaviest one.
If the monster has two Gremlins, mix only 1/2 of its total blood volume with the Gremlin powder.
If the monster has three Gremlins, mix only 1/3 of its total blood volume with the Gremlin powder.
Keep to this rule and the processing will be stable.
Break it—using powder from both Gremlins to process material from a monster that carries two, for instance—and the treated material turns unstable. The magical function it produces comes out uneven, and at worst it deteriorates faster than it would have untreated.
```

### P5 — header / body
```
For Skeleton and Ghost Types
No effective processing method has been found to date.
```

### P6 — header / body
```
For Heat-Sensitive Materials
No effective processing method has been found to date.
```

### Folio
```
30
```

## Editing and refinement record

**Pass A — source and continuity edit.** Compared line by line against the visible Japanese and the filed Volume 3 prose.

- `自己血鞣し` set to the glossary form *self-blood tanning* in all six occurrences; no variant spellings.
- `グレムリン` capitalized as *Gremlin* everywhere, per glossary; `グレムリン粉末` matched to Chapter 6's *Gremlin powder*.
- `超越者` → *Transcendent*, `魔力コントロール` → *magic-power control*, both glossary-exact.
- Corrected a first-draft conflation of `生き血` and `鮮血`. The source contrasts them inside one sentence — the material must be *living blood* or blood within thirty minutes of death, and the following clause refers back to that *fresh blood*. The filed prose already renders `鮮血` as *fresh blood*, so *living blood* / *fresh blood* keeps both distinct and consistent with the corpus.
- `死後 30 分以内` set as spelled-out *thirty minutes* in running prose; the numerals `5-10%`, `20%`, `1/2`, `1/3` are kept as figures because they are quantitative spec values, matching the source's own mixed treatment.
- `一工夫を加える` → *needs an added step*, not "needs some ingenuity" — the following paragraph is the step itself, so the concrete reading is the supported one.
- `目方が重い` → *heaviest*; weight, not size.
- `安定的処理が可能` / `不安定化する` kept as the stable/unstable pair so the rule and its violation read as a matched consequence.
- `未処理状態よりも劣化が早くなる` → *deteriorates faster than it would have untreated*; the comparison is to the untreated material, not to a slower method.
- 幽霊系 mapped to the glossary's existing *ghost type* rather than coining a separate form for 系 vs 型 — the source uses both for the same monster body-type category.

**Pass A: complete**

**Pass B — publication-English refinement.** Reread as finished English reference copy.

- Headers regularized to a single `For …` pattern across all six panels. The source's `〜の場合` is uniform, and a uniform English construction is what an English-edition designer would set; "In the case of …" six times reads as translationese.
- `そのままでは自己血を弾いてしまう` first drafted as "repels self-blood as-is" — the hyphenated adverbial is stiff display copy. Rewritten to *it repels self-blood as they are*, which also fixes the number agreement with the plural monsters.
- The P3 procedure was drafted as three clauses joined by "and", producing three sentence openings in a row on the same rhythm. Rewritten into an imperative sequence — *Raise … skip … and boil …* / *Reduce … once … simply carry out …* — which reads as instructions rather than a description of instructions.
- `くまなく覆われた` → *covered … with no gaps left*, avoiding the calque "covered thoroughly".
- P4's violation sentence was drafted with a subordinate "If you break the rule, for example by …". Recast as an imperative with an em-dash parenthesis, *Break it—using powder from both Gremlins …—and*, which matches the preceding *Keep to this rule and …* and makes the rule/consequence pairing visible at a glance.
- `発揮される魔法的な機能にムラができ` → *The magical function it produces comes out uneven*; "unevenness occurs in the magical function exhibited" is the literal calque and is unreadable at this type size.
- P5/P6 share one sentence in the source and share one identical sentence in English — deliberately not varied, because the source's repetition is the point.
- Present tense throughout: this is a current-state technical reference, not backstory.

**Pass B: complete**

### Correction passes

The first render was rejected and took three targeted passes. Recorded because two of the three defects were caused by *my own instructions*, not by the renderer.

**Pass 1 — chip overspill erased the panels' outer top rule.** The chip rectangles were painted about 5 px oversized on every side, covering the outermost top rule with white on all four panels (verified at (300, 254): source rule colour, output pure white). Separately, the P2 line-1 chip had grown to x 675 — exactly where the innermost right rule begins — and had swallowed two of that panel's three right-hand rules. Root cause of the second defect was the English line break, not the renderer: the header had been set as a very long line 1 over a two-word line 2, inverting the source's own shorter-then-longer shape. Re-broken to `For Using Blood, Sap` / `and the Like as Material`, and a ≥15 px clearance assertion added for every chip. P4's line pitch was also 36 px against 39 px elsewhere, a fit compromise on the densest panel; it had ~80 px of spare room and was returned to 39 px.

**Pass 2 — masked pixel copy was the wrong instruction.** Pass 1 was told to restore the rules by masked pixel copy from the source, the discipline that worked for the s-p026/s-p027 artwork. It cannot work here: in the source the Japanese chip is *opaque and hides* the middle and inner strokes beneath it, so for those coordinates no source rule pixel exists to copy. That is exactly why the strip came out white. Wherever the English chip is narrower than the Japanese chip it replaced, the exposed strip was left blank — P1 x 397–444 and P4 x 1172–1195, on both the middle and inner strokes. The rules had to be **reconstructed**, sampling each stroke's anti-aliased cross-section from a clean unobstructed line rather than flat-filling a colour, which would have read as a harder line than the rest of the frame.

**Pass 3 — the reconstruction over-ran the corners.** Pass 2 was told to replicate each stroke "across the rule's entire extent, corner to corner", and did exactly that, so every horizontal stroke ran past the verticals and vice versa, producing a tic-tac-toe crosshatch at all eight panel corners. Fixed by specifying each rule as a **closed rectangle outline** with exact measured bands — a horizontal stroke spans only between its own rectangle's left and right verticals — plus an explicit overshoot check and a direct corner-box comparison against the source.

**Lesson for later pages with chips over ruled frames.** When a chip is opaque in the source, the geometry beneath it does not exist in the source and cannot be recovered by copying. Decide up front whether each element is *restorable* (copy) or *hidden* (reconstruct), and for anything reconstructed, specify it as a closed shape with bounds — never as a span "across the full extent", which invites corner overshoot. Sample anti-aliased profiles rather than flat-filling.

**QA-method note.** A first pass of corner verification used 120 px corner boxes and reported failures on 15 of 16 corners; the boxes were catching chip and body-text pixels, not frame pixels. Same class of error as the earlier folio measurement that caught body text on s-p028. Corner and rule checks must be restricted to the stroke bands themselves, with chip rectangles dilated ~2 px to exclude edge anti-aliasing.
